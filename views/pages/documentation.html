Documentation

The Rates API serves the euro foreign exchange reference rates published by the European Central Bank, plus cross-rates for any other base currency.

  • Base URL: https://theratesapi.com/api
  • No API key or signup. Requests are plain HTTPS GETs and responses are JSON.
  • CORS is open, so you can call it from browser JavaScript on any site.
  • The ECB publishes new rates around 16:00 CET on working days. Rates for other bases are calculated from them and rounded to 6 decimal places.
{{ code_example('overview', 'https://theratesapi.com/api/latest') }}

Latest rates

GET /api/latest returns the newest day the ECB has published. Before about 16:00 CET that is the previous working day.

Add base to quote against another currency and symbols to return only some of them. See Parameters.

{{ code_example('latest', 'https://theratesapi.com/api/latest?base=USD&symbols=GBP,JPY', latest) }}

Historical rates

GET /api/YYYY-MM-DD returns the rates for that day, from 1999-01-04 onwards. Single-digit months and days are accepted, so /api/2025-6-2 works too.

  • Weekends and ECB holidays return the previous working day, so check the date field in the response.
  • Future dates return the latest rates.

The same base and symbols parameters apply.

{{ code_example('historical', 'https://theratesapi.com/api/2025-06-02?base=USD&symbols=GBP', historical) }}

Parameters

NameDefaultDescription
baseEURCurrency to quote rates against. Three-letter code, case-insensitive.
symbolsallComma-separated currencies to return, for example USD,GBP. Case-insensitive. Unknown codes are skipped.

Give each parameter at most once; repeating one returns an error.

{{ code_example('parameters', 'https://theratesapi.com/api/latest?base=gbp&symbols=usd,inr') }}

Errors

Errors return HTTP 400 with a JSON body containing error.

WhenStatusBody
The date isn't a real calendar date in YYYY-MM-DD form400Invalid date
Unknown base, a date before 1999-01-04, or a repeated parameter400Invalid base or symbols
Unknown codes in symbols200Those codes are skipped, so rates can be {}

Retired currencies such as CYP (Cypriot pound) still work as base or in symbols for dates when the ECB published them. As the base of /api/latest, they return their last published day.

Fair use

There are no keys or rate limits today. Help keep it that way:

  • Cache responses. Rates change once per working day, and responses carry Cache-Control: public, max-age=300.
  • Don't request more often than you need to. Traffic that harms the service for others may be blocked.
