Privacy policy

Last updated 24 October 2026

The Rates API has no accounts. The website uses Google Analytics to count visits; the API itself is not tracked. Apart from that, the only personal data we handle is what any web server sees when you make a request.

What we log

When you visit the site or call the API, our web server records the request in an access log: your IP address, the date and time, the URL you requested (including any query parameters), and request headers such as your browser's user agent and the page that linked you here.

The application also logs each request's method, URL, response status and response time. That log does not include your IP address.

Why

To keep the service running, to find and fix problems, and to detect and block abusive traffic. We don't use the logs for anything else.

How long we keep it

Access logs are rotated by size: we keep the five most recent files of 50 MB each, and older entries are deleted automatically. How far back that reaches depends on how busy the service is.

Sharing

We don't sell or share the logs. We would only disclose them if the law required us to.

Cookies and tracking

The website uses Google Analytics to see how many people visit and which pages they read. When you open a page, your browser loads a script from Google, which sets cookies (_ga and _ga_BGQKLYTT79) and sends Google the address of the page, the page that linked you here, your browser and device type, and your approximate location, which Google works out from your IP address. We see reports and totals, not individual visitors. Google handles this data as described in how Google uses information from sites that use its services.

API calls are not tracked: API responses load no scripts and set no cookies.

To opt out, block cookies for theratesapi.com in your browser, or install Google's Analytics opt-out browser add-on.

Apart from that script, the site loads no scripts, fonts or other files from other companies.

Where the service runs

The Rates API is hosted on Amazon Web Services in the United States. The exchange rates come from the European Central Bank and Banca d'Italia; we don't send them anything about you.

Changes

If this policy changes, we'll update this page and the date at the top.
