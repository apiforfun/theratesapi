Try a request

Two endpoints cover everything. Both return JSON and take the same two parameters.

GET /api/latest
The newest day both banks have published.
GET /api/2025-06-02
Any day since 1999. Weekends and holidays return the previous working day.

Add base=USD to quote against another currency and symbols=GBP,JPY to return only some. Read the full reference.
